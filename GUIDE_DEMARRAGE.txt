🧠 CONCEPTS ML APPLIQUÉS
-------------------------

1. RÉGRESSION LINÉAIRE
   - Prédiction du mot suivant comme problème de régression
   - Outputs: indices des mots (0 à vocab_size-1)
   
2. CLASSIFICATION MULTI-CLASSE
   - Classification sur vocab_size classes (mots)
   - Softmax + Cross-Entropy Loss
   - Genre comme variable de condition
   
3. RÉSEAUX DE NEURONES
   - Architecture: 2 couches (cachée + sortie)
   - Activation: ReLU (couche cachée), Softmax (sortie)
   - Embeddings: projection d'indices vers espaces denses
   
4. FONCTION DE COÛT
   - Cross-Entropy: J = -(1/m) * Σ y * log(p)
   - Une loss pour chaque exemple d'entraînement
   
5. GRADIENT DESCENT
   - w_{t+1} = w_t - α * ∂E/∂w_t
   - Learning rate: α = 0.001
   - Rétro-propagation pour les gradients
   
6. OPTIMISATION MATRICIELLE
   - Utilisation de NumPy pour les calculs matriciels
   - Batch processing pour efficacité
   - Vectorisation complète (pas de boucles Python)

🔧 PARAMÈTRES IMPORTANTS
-------------------------

Modèle:
    - embedding_dim: 16 (dimension des vecteurs de mots)
    - hidden_dim: 32 (neurons dans la couche cachée)
    - SEQ_LEN: 10 (taille du contexte en input)
    - vocab_size: ~4,000 (nombre de mots uniques)
    - num_genres: 5 (nombre de genres musicaux)

Entraînement:
    - batch_size: 128 (exemples par batch)
    - learning_rate: 0.001 (paramètre du gradient descent)
    - num_epochs: 10-15 (itérations complètes)
    - early_stopping: patience=3 (arrêt si pas d'amélioration)

Génération:
    - max_length: 40-50 tokens
    - temperature: 0.7-1.2
      * 0.7 = plus déterministe, cohérent
      * 1.0 = normal
      * 1.2 = plus créatif, varié
