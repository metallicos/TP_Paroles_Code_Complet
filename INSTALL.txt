📊 ARCHITECTUR DU MODÈLE
────────────────────────────────────────────────────────────────

Concepts du cours appliqués:
✓ Régression        → Prédiction mot suivant
✓ Classification    → Intégration genre musique
✓ Réseaux de neurones    → 2 couches avec embeddings
✓ Gradient Descent  → Optimisation des poids
✓ Cross-Entropy     → Fonction de coût
✓ Backpropagation   → Calcul des gradients

Architecture:
  Séquence (10 tokens) → Word Embeddings (16D)
                      ↓
                Genre Embeddings (16D)
                      ↓
            Concatenation & Dense Layer 1 (ReLU)
                      ↓
            Dense Layer 2 (Softmax)
                      ↓
            Distribution: prochain mot

🆘 DÉPANNAGE
────────────────────────────────────────────────────────────────

Python/pip non trouvé?
  Ubuntu: sudo apt-get install python3 python3-pip
  macOS: brew install python3
  Windows: python.org

Dépendances manquantes?
  pip3 install -r requirements.txt

Dataset non trouvé?
  Vérifiez que spotify_songs.csv est dans le même dossier

Entraînement trop lent?
  C'est normal sur CPU (5-15 min)
  Réduisez NUM_EPOCHS ou BATCH_SIZE si urgence

Pas assez de mémoire?
  Réduisez BATCH_SIZE: 128 → 32 ou 64


🎓 CONCEPTS MATHÉMATIQUES
────────────────────────────────────────────────────────────────

Utilisés dans le modèle:
  • Embeddings: word2vec simplifié
  • Forward Pass: z = Wx + b, a = ReLU(z)
  • Softmax: pour probabilités multi-classe
  • Cross-Entropy: -Σ y_i * log(ŷ_i)
  • Gradient Descent: W ← W - α∇L
